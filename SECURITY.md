# Security

Do not post API keys, passwords, cookies, tokens, account information or exploit details in public issues.

For a vulnerability, use the repository's **Security → Report a vulnerability** feature if the maintainer has enabled private vulnerability reporting. If that option is unavailable, open a minimal issue asking for a private reporting channel without including sensitive details.

Relevant areas include custom CSS parsing, imported settings, caption mirroring and extension permissions. The extension intentionally rejects URLs and CSS rule blocks in custom declarations, copies only supported caption elements/text into PiP, and does not send data to an extension-operated server.
